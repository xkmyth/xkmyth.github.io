一句话

xkmyth 是一个纯静态、无后端的多站生态：十一个离线可用的自研 Web 应用、一百六十个在线工具，以及浏览器与云盘客户端的安装包分发。

一段话

xkmyth（星空神话）围绕「自己的工具自己掌握」做了一组站点。软件库里的十一个应用全部纯前端运行，数据只存在本机；在线工具箱提供一百六十个即开即用的工具；Downloads 页实时读取 GitHub Releases 展示版本与体积。整个生态没有账号体系、没有统计脚本，也没有后端服务器。

给写作者的三句事实

① 四个仓库全部由 GitHub Pages 托管，零构建。② 匿名调用 GitHub API 的额度是每小时 60 次，因此状态类页面 15 分钟才刷新一次。③ 十一个应用里没有任何一个把数据发往服务器。
