纯静态 零后端 数据在你本机 DeepSeek 直连

内置 AI 助手

右下角那颗金色按钮就是它（快捷键 Ctrl / ⌘ + J）。它直连 DeepSeek 的 chat/completions，没有中间服务器：你的问题从浏览器直接发出去，会话只写在本机 localStorage['xk-ai-chat']，刷新页面还在，清空就没了。

它知道这个站点有什么：160 个在线工具、11 个本地数据应用、按场景分好的工具合集在哪、文档在哪。它不知道你的私事，也不该被当成搜索引擎。

看接口说明 按场景找工具
先说清楚风险：纯静态站点没有后端，任何写进前端的 key 对访客都是公开的。这一页用的是「演示 key」，放在 /js/ai-key.js 里，谁都能看到。正式对外前请到 platform.deepseek.com 轮换，并在设置里换成你自己的 key（只存在你的浏览器），或者按下面的示例改成后端代理。

直接调用 API

浏览器里最小可用的流式请求，和助手用的是同一套参数：

async function ask(prompt, key) {
  const res = await fetch("https://api.deepseek.com/chat/completions", {
    method: "POST",
    headers: { "Content-Type": "application/json", Authorization: "Bearer " + key },
    body: JSON.stringify({
      model: "deepseek-chat",
      stream: true,
      max_tokens: 800,
      messages: [
        { role: "system", content: "你是 xkmyth 站内助手，中文回答，先结论后做法。" },
        { role: "user", content: prompt }
      ]
    })
  });
  if (!res.ok) throw new Error("HTTP " + res.status);
  const reader = res.body.getReader();
  const dec = new TextDecoder();
  let buf = "", out = "";
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    buf += dec.decode(value, { stream: true });
    const lines = buf.split("\n");
    buf = lines.pop();
    for (const line of lines) {
      if (!line.startsWith("data:")) continue;
      const data = line.slice(5).trim();
      if (data === "[DONE]") continue;
      const delta = JSON.parse(data).choices?.[0]?.delta?.content;
      if (delta) { out += delta; console.log(out); }
    }
  }
  return out;
}
curl 适合在终端里先确认 key 和网络都通。 
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"用一句话说明什么是纯静态站点"}]}'

本机数据自查

11 个应用全部把数据留在浏览器里，键名统一是 xk- 开头。想知道自己攒了多少、占多少字节：

打开数据台账 本地密码库 看这些东西怎么做的

台账只读本机存储，删之前会让你连点三下确认——它自己不会偷偷清数据。

三步上手

  1. 先跑通一条请求：用上面的 curl 或浏览器示例确认 key 能用，再看返回的流。
  2. 再换 key 归属：演示 key 只够试；换成自己的，或者把请求挪到你的后端，前端只留一个转发地址。
  3. 最后接站点数据：拿 /search-index.json 喂给检索，用 /sitemap.xml 做镜像，工具直接链详情页。
