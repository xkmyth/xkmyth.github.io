CI 抓到的一次真实事故

工具站的检查工作流提交后一直不跑，Actions 里连一条 run 都没有。

2026-10-17站务日志

工具站的检查工作流提交后一直不跑，Actions 里连一条 run 都没有。原因是文件被 PowerShell 写成了 GBK，GitHub 解析不出 YAML 结构，于是悄悄忽略了它。

教训写进了决策日志：仓库里的文件一律 UTF-8 + LF，写文件时显式指定编码；另外，往非 main 分支 push 不会触发 on.push.branches:[main] 的工作流，要看 PR 事件。
