Getting Started

十分钟上手

从下载到跑起来，只要四个动作。每一步都给出验证方式。

这份指南适合谁

🪟 Windows 用户

Windows 10 / 11，64 位。解压即用，不写注册表、不占系统盘。

📱 Android 用户

Android 8.0 及以上。APK 直装，装完登录你自己的云盘地址即可。

💽 想装系统的人

手上有 U 盘（≥ 8 GB）和一台能进 BIOS 的机器，走「安装定制系统」那节。

四步走完

1️⃣ 挑对安装包

下载页有四张卡：浏览器版（Windows / Android）与云盘版（Windows / Android）。

  • 浏览器版：把星空浏览器带到你现有的系统上，装完就能用。
  • 云盘版：搭配自建 Cloudreve 云盘，桌面端 + 手机端 + WebDAV 三件套。

去 Downloads ↗

2️⃣ 校验完整性

大文件下载过程中可能被中间设备改写，装之前花 10 秒核一下 SHA256。

certutil -hashfile xkmyth-browser-win-x64.zip SHA256

校验怎么做 ↗

3️⃣ 解压 / 安装 / 首次运行

Windows 包是免安装绿色版：解压到任意目录，双击主程序。Android 装 APK 需要在系统设置里允许「安装未知来源应用」。

首次运行可能遇到 SmartScreen 拦截 —— 未签名程序的正常现象，点「更多信息 → 仍要运行」。

4️⃣ 接上你自己的云

云盘版首次启动会让你填私有云盘地址；填完即可同步桌面与手机。备份工具（Restic / Hyper Backup 等）用 WebDAV 接入同一个地址。

回文档中心 ↗

装完自查清单

  • ✅ 主程序能正常启动，界面是深空底 + 金色点缀
  • ✅ 下载页显示的版本号与你解压出来的版本一致（页面实时读 Releases）
  • ✅ 云盘客户端能登录，能上传一个小文件再下载回来
  • ✅ 手机端与桌面端能互相看到同一个目录
  • ✅ 需要备份的话，WebDAV 地址已在备份工具里跑通过一次

三个最常见的坑

解压后双击没反应 / 被安全软件直接删掉
先确认压缩包完整（对照体积），再把它加入安全软件白名单后重新解压。被拦下的文件通常已经被隔离，重新解压一次最省事。
安卓提示「应用未安装」
多半是旧版本残留签名冲突：先在设置里卸载旧版（不是覆盖安装），再装新包。空间不足也会报同样的错，看一眼剩余容量。
云盘连不上 / 一直转圈
先确认地址写对了（协议 + 域名 + 端口），再试试浏览器能否打开同一个地址。自建服务如果只在内网，出门在外需要走内网穿透或 VPN。
