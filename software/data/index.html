XK Data

把浏览器里属于本站的数据全列出来：每个键存了什么、占多大、能导出也能清。没有隐藏项，也不上传。

纯本地 可导出 可一键清空
← 软件库

这里列的是什么

本站所有自研应用都只把数据写在你自己的浏览器里。这一页把它们全部列出来：键名、用途、体积，以及「导出」和「清空」两个按钮。

列表是运行时扫出来的，不是硬编码的清单 —— 哪怕以后加了新应用，这里也会自动出现。

体积怎么算

按 Blob 的真实字节数算（UTF-8），不是字符数。中文一个字三字节，所以看着短的键也可能不小。

浏览器给每个站点大约 5 MB 的 localStorage 额度。用得多了先看排在最前面的那几项。

清空会发生什么

清空是立刻生效、不可撤销的。导出 JSON 之后再清，是唯一稳妥的顺序。

「清理站点缓存」只动可重建的缓存（版本号、状态页、索引），不会碰你的笔记、账本、保险箱。

导出格式

单个键导出成 {key, value, exportedAt}；全部导出成一个对象，键名做 key。保险箱导出的是密文，没有主密码打不开 —— 这符合预期。
