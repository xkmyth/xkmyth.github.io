共同点

十一个应用，一条底线

不收费

没有任何付费墙、注册、试用期，打开即用。

不联网也转

数据全程在浏览器里，断网照样工作，只有状态类页面会读公开 API。

不留痕

没有账号体系，没有埋点；数据在 localStorage，清掉浏览器数据即彻底消失。

看得懂

每行代码都在 GitHub 上，改一行刷新就能跑，不需要构建工具。
