下载与安装

1️⃣ 挑对包

Windows 用户取 x64.zip（免安装绿色版，解压即用）；Android 用户取 .apk；系统镜像走私有云盘。

2️⃣ 校验完整性

大文件建议核对 SHA256。Windows：certutil -hashfile 文件名 SHA256；Linux/macOS：shasum -a 256 文件名。

3️⃣ 首次运行

Windows 可能提示「未知发布者」，属未签名程序的正常提示；Android 安装 APK 需在系统设置里允许「安装未知来源应用」。

安装定制系统

💽 写盘

常见问题

桌面程序提示「Windows 已保护你的电脑」怎么办？
这是 SmartScreen 对未签名程序的默认拦截。点「更多信息」→「仍要运行」即可；如果你愿意，也可以在本地对 exe 做一次 SHA256 校验，确认下载过程没有损坏。
页面上的版本号和下载数为什么是「读取中…」？
这些数字由浏览器实时向 api.github.com 请求 Releases 得到。若网络受限（比如没连上 GitHub），页面会自动降级为「最新版见 Releases」直链，不影响下载。
绿色版和安装版有什么区别？
目前 Windows 端提供的是免安装绿色版：解压到任意目录双击主程序即可，不写注册表、不占系统盘。想卸载直接删目录。
云盘怎么用？需要注册吗？
云盘是自建服务（Cloudreve），通过私有云盘地址访问，不走第三方账号体系。桌面客户端、安卓客户端与 WebDAV 三条路径任选，备份工具（如 Restic / 群晖 Hyper Backup）可直接用 WebDAV 接入。
为什么要用 GitHub Releases 而不是网盘？
GitHub Releases 自带全球 CDN、断点续传与版本归档，且下载地址永久稳定；私有云盘作为国内直连的备用通道。两边都放，谁快用谁。

进阶

🔐 校验和

发版规范要求每个 Release 附 SHA256SUMS.txt。拿到文件后在终端执行：

sha256sum -c SHA256SUMS.txt

🗂️ WebDAV 备份

云盘支持 WebDAV，把备份目标指向 https://你的云盘域名/webdav/ 即可，客户端会自动分块上传。
