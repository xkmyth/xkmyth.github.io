术语表

看到不懂的词就查这里

Releases
GitHub 的发布记录，一次发布带多个资产文件；本站版本号都从这里读，不手写。
资产（asset）
发布里的单个文件，例如 xkmyth-browser-win-x64.zip。
Pages
GitHub 的静态托管，直接发布仓库根目录，没有后端。
WebView 壳
客户端只提供一个浏览器容器与少量原生能力，页面逻辑跑在本地 HTML 里。
SHA256
文件指纹。下载后自己算一遍并与发布页的值比对，才算校验过。
PBKDF2
把口令拉伸成密钥的算法；本站保险箱用 15 万轮，让暴力猜测变慢。
AES-GCM
带认证的对称加密，密文被改过会直接解不开，比裸 AES-CBC 更安全。
localStorage
浏览器本地键值存储，同源共享、永不过期，清浏览器数据即消失。
localStorage 上限
通常 5–10 MB，本站各应用都做了容量提示与导出。
命令面板
⌘K / Ctrl+K / 斜杠唤起的全站跳转与搜索浮层。
reduced-motion
系统级「减少动态效果」偏好；本站所有动画在这项开启时关闭。
DPR
设备像素比。星空 canvas 按 DPR 渲染但上限 2，避免高分屏烧 GPU。
CI（Actions）
推 PR 时自动跑检查：JS 语法、HTML 解析、锚点、本地引用。
分支保护
main 只接受 PR 合并，禁止强推与删除，保证历史可追。
匿名 API 额度
GitHub 对未登录请求限 60 次/小时/IP，本站因此大幅降低刷新频率。
TOTP
基于时间的一次性口令，工具箱可本地生成，密钥不出浏览器。
CIDR
形如 192.168.1.0/24 的网段表示法，工具箱可算可用地址范围。
JWT
三段式令牌（头/载荷/签名），工具箱只做本地解码，不校验签名、不发送。
Markdown
轻量标记语言；笔记应用先转义再解析，避免把输入当 HTML 执行。
WebCrypto
浏览器原生加密 API，本站所有哈希与加密都走它，不加载第三方库。
发布规范
每个资产附 SHA256、写清适用平台、版本号与代码里的版本号保持同步。
