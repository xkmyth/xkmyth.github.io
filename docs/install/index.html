安装详解

三个平台怎么装、卡在哪、怎么绕过去。

Windows：绿色版三步

1️⃣ 解压

下完的 .zip 右键「全部解压缩」到任意目录，建议路径里不要有中文和空格。

2️⃣ 放行

首次运行如果弹 SmartScreen，点「更多信息 → 仍要运行」。程序没有代码签名证书，这是正常提示。

3️⃣ 建快捷方式

对主程序右键「发送到 → 桌面快捷方式」，之后从桌面直接进。

Android：跳过一次未知来源

  1. 下载 .apk 到手机（用手机浏览器打开下载页最稳）。
  2. 在文件管理器里点开安装包，系统会提示「已禁止安装未知应用」。
  3. 按提示进入「设置 → 允许来自此来源的应用」，回到安装界面继续。
  4. 安装完成若提示「应用未安装」，先卸载旧版再装 —— 多半是签名冲突。

Android 8.0 及以上。装完桌面会出现带星形图标的入口。

定制系统镜像

  1. 准备 U 盘：容量 ≥ 8 GB，写入会清空全部数据。
  2. 写盘：用 Ventoy 或 Rufus 把镜像写进去（Ventoy 的好处是盘里可以放多个镜像）。
  3. 进 BIOS：开机连点 F2 / F12 / Del（各家不同），把 U 盘调到启动顺序第一位。
  4. 安装：跟随向导分区，选好目标磁盘再动手 —— 这一步出错会丢数据。
  5. 首次开机：主题、浏览器、云盘客户端已经预装到位，登录自己的云盘地址即可。

⚠️ 装系统前请确认

  • 重要文件已经备份到另一块盘或云端
  • 记下了目标磁盘的容量，别选错盘
  • 知道怎么进 BIOS、怎么改回启动顺序

装完第一步建议做一次校验：校验与验证 →
