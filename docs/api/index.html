用到的 GitHub 接口

全部是公开只读

端点取什么谁在用
api.github.com/repos/xkmyth/xkmyth/releases?per_page=5版本号、资产体积、下载次数、时间首页下载卡、Downloads、版本日志
api.github.com/repos/xkmyth/xkmyth/releases/latest最新版本标签状态页
api.github.com/repos/OWNER/REPO/commits?per_page=1最近一次提交状态页
api.github.com/repos/OWNER/REPO/actions/runs?per_page=1最近一次 CI 结果状态页

全部匿名、无 token。匿名额度 60 次/小时/IP，所以状态页 15 分钟才刷一次，且四仓并发合并成一次批量。

站内搜索索引

search-index.json

命令面板（点导航栏的 ⌕ 或按 /、Ctrl+K）读的是根目录下的 /search-index.json。格式如下：

{
  "generated": "2026-10-17",
  "items": [
    { "title": "软件库", "url": "/software/", "kind": "page", "kw": "应用 离线 工具" },
    { "title": "XK Vault", "url": "/software/vault/", "kind": "app", "kw": "加密 密码 保险箱" }
  ]
}

有 kw 就参与关键词加分，没有就只按标题与 URL 匹配。索引取不到时，命令面板会退化成扫描当前页面链接，仍然可用。

前端可用的公共函数

window.xkmythUI

成员说明
xkmythUI.toast(msg, kind)弹出提示，kind 取 'ok' / 'bad'
xkmythUI.copy(text)复制文本，自动降级到 execCommand
xkmythUI.palette()打开命令面板
xkythmUI 主题html[data-theme="light"] 切换，键名 xk-theme

任何元素加 data-copy="#target" 或 data-copy=".sel" 就能被点一下复制，取自目标的 value 或 textContent。
