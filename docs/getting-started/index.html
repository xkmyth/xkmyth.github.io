十五分钟路线

从零到跑起来

第 1 步 · 2 分钟
确认你要什么

要浏览器就下 Downloads 里的 xkmyth-browser；要云盘客户端就下 xkmyth-cloud；只要工具就去 工具目录。别一次下一堆，先跑通一个。

第 2 步 · 3 分钟
下载与校验

从 Downloads 取最新资产，记录 SHA256，按 校验与验证 里对应平台的命令跑一遍。数字对得上再解压。

第 3 步 · 5 分钟
解压安装

Windows 压缩包解压到你自己的目录即可运行，不写注册表；APK 允许「安装未知来源」后安装。细节见 安装详解。

第 4 步 · 5 分钟
接上你自己的服务

浏览器与云盘客户端都是壳，地址由你填：自建 NAS、私有云盘、任意 WebDAV/S3 都行。默认不连任何第三方服务器。

收尾 · 30 秒
收藏三个入口

软件库 处理日常杂事、在线工具箱 临时救急、状态页 看上线情况。

先选路线

三种人，三条路

你是谁推荐路线别做的事
只想用工具，不碰下载工具目录 → 挑一个用 → 收藏别去装客户端，浏览器里已经够用
要装浏览器 / 云盘客户端Downloads → 校验 → 安装别跳过校验，也别用来路不明的二次打包
想自己改、自己发版参与开发 → fork → PR别直推 main，分支保护会拦你

自查清单

跑完之后对一遍

  • 下载的资产名和 Releases 页面上的完全一致（连大小写）。
  • SHA256 与你记录的一致，而不是与页面上的文字一致。
  • 解压目录里没有多余的可执行文件，也没有杀软提示的自解压壳。
  • 首次启动没有要求你注册账号或填手机号。
  • 你在设置里填的上游地址是你自己的服务，不是别人的默认服务器。
  • 关掉网络后，本地功能仍然可用（纯前端应用都满足）。
