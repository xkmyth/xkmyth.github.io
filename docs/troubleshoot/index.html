排障手册

症状 → 原因 → 处理，三步之内没解决再去提问。

按「症状 → 原因 → 处理」排。三步之内没解决，再带上下文去 提一个问题。

下载

下载页显示「最新版见 Releases」
原因：浏览器拿不到 GitHub API 数据（网络波动或被拦截）。
处理：点那个直链去 Releases 页面手动下；页面的降级逻辑不会影响可用性。
下到一半失败 / 速度只有几 KB
原因：Releases 走的是国外线路，跨时段差异很大。
处理：换时段或换网络重试；用支持断点续传的下载器往往比浏览器快。

Windows

双击主程序没反应
原因：多被安全软件拦截并已隔离，或压缩包不完整。
处理：对照体积确认下载完整；把程序目录加入白名单后重新解压。
提示「缺少 VCRUNTIME140.dll」之类
原因：系统缺少运行库。
处理：装一次微软官方的 Visual C++ 运行库（x64），重启再试。
界面字小 / 高分屏模糊
原因：缩放比例不是整数或系统兼容性设置不当。
处理：右键主程序 → 属性 → 兼容性 → 更改高 DPI 设置，勾选「替代高 DPI 缩放行为」。

Android

「应用未安装」
原因：与旧版签名不一致，或空间不足。
处理：先完整卸载旧版，再装新包；同时看一眼剩余空间。
装好了但打不开 / 白屏
原因：WebView 组件过旧。
处理：在应用商店更新「Android System WebView」或 Chrome，再重开。

云盘

一直转圈连不上
原因：地址写错、服务未启动、或服务只在内网。
处理：先在同一网络用浏览器打开该地址；外面访问需要内网穿透或 VPN。
WebDAV 备份工具连不上
原因：协议前缀写成了 http 而服务只开 https，或端口不是默认的 5212。
处理：补齐协议与端口；路径一般要带 /dav 后缀。

站点

状态页四张卡全是「读取失败」
原因：GitHub 匿名 API 额度（60 次/小时/IP）被同一出口的其他人用光了。
处理：等一段时间再刷新；页面已把刷新间隔放宽到 15 分钟来降低消耗。
工具箱某个工具算不出结果
原因：输入不合法（例如进制转换里写了 1.5 或 0x1F），或当前浏览器不支持 WebCrypto（需要 https 或 localhost）。
处理：按提示修正输入；哈希与随机类工具请用 https 访问。
