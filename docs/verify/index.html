校验与验证

下载完成后的第一件事不是双击，而是算一次指纹。

为什么要校验

大文件在下载途中可能被中间设备改写，也可能你拿到的是第三方转存版本。SHA256 是把整个文件算成一串指纹：只要内容变了一个字节，指纹就完全不同。

哈希对上，只证明「这个文件与作者发布的一致」 —— 它不能证明程序本身没有 bug，但能证明它没被人在路上改过。

三个平台怎么算

🪟 Windows

命令提示符里：

certutil -hashfile 文件名 SHA256

或在 PowerShell：Get-FileHash 文件名 -Algorithm SHA256

🍎 macOS

终端里：

shasum -a 256 文件名

🐧 Linux

终端里：

sha256sum 文件名

不想开终端？

用工具箱里的哈希工具：把文件拖进去，指纹在浏览器里算出来，文件不会上传到任何服务器。

比对时注意

大小写与空行无关
哈希值不区分大小写，逐字符比对即可；复制时别把行尾说明文字带进去。
发布方应该公布什么
理想形态：每个 Release 都附一个 SHA256SUMS.txt，列出该版本所有资产的指纹。在落实之前，本条留在 路线图 的「进行中」里。
对不上怎么办
停止运行，重新下载一次（换网络或换时段）。仍然对不上就是上游文件有问题，请在 支持页 说明文件名、体积与两次算出的指纹。
