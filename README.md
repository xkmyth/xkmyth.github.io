# 星空神话 xkmyth · 官方网站

xkmyth（中文名 **星空神话**）生态的官方主页。

- 主站：https://xkmyth.github.io/
- 工具站：https://xkmyth.github.io/Timarsky/
- 关于/生态：https://xkmyth.github.io/about/
- 发行仓库（下载）：https://github.com/xkmyth/xkmyth/releases

## 生态五件套

| 组件 | 说明 |
| --- | --- |
| 🖥️ xkmyth 浏览器 | Electron 内核 · 星空 UI · 无边框多标签 · 广告拦截 · 一键翻译 · Windows / Android |
| 💾 xkmyth 云盘 | 基于 Cloudreve 的私有云盘 · IPv6 + DDNS · HTTPS · WebDAV · 分享免登录下载 |
| 🌐 xkmyth 官网 | 主站 + 工具站 + 关于页，GitHub Pages 托管 |
| 📀 xkmyth 定制系统 | Windows 11 25H2 深度定制镜像 · 星空主题 · 装机即用 |
| 📱 xkmyth 安卓端 | 浏览器 / 云盘 两个 APK |

## 技术

纯静态站点：`index.html` + `style.css` + `main.js`（Canvas 星空动画），无构建、无依赖，改完直接推。
