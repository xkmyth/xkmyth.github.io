🌌 底色

深空底 #04060f，卡片层 #0a1226。所有页面从这一层开始加光。

✨ 主色

金色 #fcd34d 用于强调与主按钮，冰蓝 #9ae3ff 用于链接与点缀。金色只做点睛，别铺满。

标识

标识是一个金色星形加一条冰蓝行星轨道环，纯 SVG、无位图。可直接复制下面这段用：

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100">
  <circle cx="50" cy="45" r="16" fill="#fcd34d"/>
  <path d="M50 20v50M25 45h50" stroke="#fcd34d" stroke-width="6"/>
  <ellipse cx="50" cy="66" rx="26" ry="8" stroke="#9ae3ff"
           stroke-width="3" fill="none" transform="rotate(-15 50 66)"/>
</svg>

字体与质感

🔤 字体

系统 UI 字体栈优先，不加载 Web 字体（省一次网络往返）。中文按系统默认。

🪟 玻璃

卡片 = 半透明底 + 1px 细边 + 8% 高光，圆角 16px；hover 抬升 2px。

🎞️ 动效

仅用 160–260ms 的位移/透明度；全部尊重 prefers-reduced-motion，切后台暂停星空。
