GitHub Pages
静态托管、全球 CDN、自带 HTTPS。没有它就得多租一台服务器。
GitHub Releases
安装包的存放与分发，顺带提供了版本号、体积、下载次数的 API。
GitHub Actions
PR 上的自动检查：JS 语法、HTML 解析、锚点与本地引用。
WebCrypto（浏览器原生）
哈希、PBKDF2、AES-GCM、TOTP 全部不需要第三方库。
Canvas 与 MediaRecorder
图片压缩与录音的基础能力，浏览器自带。
系统字体栈
不下载字体文件也能有稳定的排版，省掉几百 KiB。
所有提过 issue 的人
每一条能复现的问题描述，都比十句「挺好用」有用。
