下载与安装

页面上的版本号、体积、下载数是怎么来的？
全部由浏览器实时向 api.github.com 请求 Releases 数据后渲染，缓存 10 分钟。网络不通时自动降级成「最新版见 Releases」直链，不影响下载。
为什么 Windows 会提示「未知发布者」？
因为程序没有购买代码签名证书。这是免签名软件的常态提示，不是病毒告警。核对 SHA256 与 Release 说明一致后再运行，风险就只剩「你信不信这个项目」这一件事。
绿色版和安装版有什么区别？
目前 Windows 端提供免安装绿色版：解压到任意目录双击即用，不写注册表、不占系统盘；卸载就是删目录。好处是干净，代价是没有开始菜单快捷方式和自动更新服务。
下载慢 / 中途失败怎么办？
GitHub Releases 在国内直连波动较大。可以换网络、换时段重试，或者走私有云盘的备用通道；已经下到一半的文件建议用支持断点续传的下载器接着下，而不是从头来。

使用与数据

云盘需要注册账号吗？
不需要走第三方账号体系。云盘是自建服务（Cloudreve），地址由你填写，账号也在你自己的服务端。桌面端、安卓端、WebDAV 三条路随便挑。
网站会不会收集我的数据？
四站都是纯静态页面，没有埋点、没有第三方统计脚本、没有登录。唯一的对外请求是向 GitHub 的公开 API 读版本与仓库状态，以及你主动点开的站外链接。
在线工具箱会把我的输入传走吗？
不会。30 个工具全在浏览器本地计算（哈希与随机数走 WebCrypto），页面不发起任何与输入相关的网络请求。断网也能用。
状态页的数字多久更新一次？
15 分钟。原因很实在：一轮刷新要打 12 次 GitHub API，而匿名额度只有 60 次/小时，刷太快会被限流然后整页显示失败。想立刻看最新的就点页面上的「刷新」按钮。

生态与协作

工具站的「速查模块」和「在线工具箱」有什么区别？
速查模块是给人看的内容卡片（系统技巧、CAD 快捷键、Office 操作等，目前 27 个模块），在线工具箱是能直接用的小工具（目前 30 个）。一个查，一个用。
我发现页面有错字 / 死链 / 样式问题，去哪说？
去 支持页 选对应仓库开 Issue，或者直接提 PR —— 每个仓库都有 COORDINATION.md 和 PR 模板，CI 会自动跑 HTML 结构、链接、锚点与 JS 语法检查。
为什么一个仓库一个站点，不合并成一个？
GitHub Pages 是按仓库独立部署的，四站合并需要引入构建链；而多 agent 并行维护时，构建链是事故高发区。当前选择是「统一设计语言，各站独立演进」，代价是多复制几份 CSS，收益是任何一站坏了不影响其它站。
文档里说的东西和实际对不上怎么办？
以仓库里的实际文件为准 —— 站点和文档都可能滞后。发现不一致欢迎开 Issue 点名哪一页哪一句，这属于我们会优先修的那类问题。
