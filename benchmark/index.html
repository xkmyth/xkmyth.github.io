怎么自己测

三条命令，别信感觉

# 1. 体积与请求数
curl -s -o /dev/null -w "size=%{size_download} time=%{time_total}\n" https://xkmyth.github.io/

# 2. 打开 DevTools → Network → 勾选 Disable cache → 刷新，看 Transfer 总量
# 3. Lighthouse（移动端 + 桌面端各跑一次），重点看 TBT 与 CLS

这套站点的目标是：首屏请求数 ≤ 6、传输 ≤ 60 KiB、CLS 接近 0。达不到就说明有人往页面里塞了多余的东西。

性能上的取舍

明确知道放弃了什么

不做视觉重特效

星空是 canvas，只在可见时绘制，DPR 上限 2，切后台立刻停。

不做无限滚动列表

工具与截图都在本地，一次性渲染；数据量变大前不引入虚拟滚动。

不做 SSR

静态 HTML 已经是「构建期渲染」，没有服务端可做，也不需要。
