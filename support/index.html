提交前自查

✅ 三件事

  • 用的哪个包、哪个版本（下载中心页面上能看到）
  • 操作系统与位数（Win11? Android 版本?）
  • 复现步骤：点哪里、期望什么、实际什么

🔎 先搜一下

同一个 bug 经常已经有人说过了。Issue 列表里搜关键词（比如「闪退」「APK」「WebDAV」），比重复提一条更快得到确认。

常见疑问

提了 Issue 多久会有回应？
这是个人项目，通常 1–3 天内会看一眼。带完整复现步骤的会快很多；纯「不能用」三个字的，往往只能来回问几轮。
可以直接发 PR 吗？
可以，而且欢迎。每个仓库都有 COORDINATION.md：从自己的分支提交，commit 前缀写清 [a1]/[a2]/[a3] 或说明身份，main 分支受保护、需要 PR 合并，CI 会跑 HTML 结构与 JS 语法检查。
能自己改下载页的版本号吗？
不用改 —— 版本号是从 GitHub Releases 实时读取的。发版只需要打 tag、上传资产，页面自己就更新了。
