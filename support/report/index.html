怎么提问题

把上下文写全，问题就修得动。

一个能修的问题和一句「用不了」之间，差的是四样东西：在哪、做了什么、看到什么、期待什么。填齐这四个，修起来就是分钟级的。

先做这三件小事

🔁 刷新 / 重开

页面类问题强制刷新一次（Ctrl+F5），程序类问题完全退出再启动。

🧪 换个环境

换浏览器、换网络、换设备各试一次，能快速区分「偶发」和「必现」。

🔍 查排障

排障手册 和 常见问题 里可能已经有答案。

别贴这些

别把密钥、令牌、密码贴进公开 Issue
公开 Issue 是永久可搜索的。发现自己的令牌已经泄漏，第一件事是去平台吊销并重新签发，而不是删评论 —— 删之前可能已经被抓取。
别贴完整日志里的隐私路径
日志里的用户名、内网 IP、云盘域名可以打码，问题描述通常不需要它们。
安全问题别在公开 Issue 里写利用细节
先开一个只写摘要的 Issue 要求私下渠道，详见 安全与校验。
