凡是要求你「先关注公众号 / 先注册 / 先装下载器」的所谓镜像，都不是这里的。本站只提供上面三条。

自建镜像

想帮别人加速，这样最省事

  1. 拉取最新资产：gh release download --repo xkmyth/xkmyth --pattern "*.zip"，或者用 API 自己拼 URL。
  2. 校验后再转发：算一遍 SHA256，和发布页对得上再放进你的镜像目录。
  3. 对外发布时写清「镜像来源 + 同步时间 + SHA256」，别只给一个网盘码。
  4. 同步脚本建议每天一次，别做实时镜像，免得把半成品转发出去。

本站不会自动收集镜像列表。你想让这里收录，请按 怎么提问题 发 issue，附镜像地址与校验值。
